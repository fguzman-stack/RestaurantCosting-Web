01 / Redeem and install

Download the Windows 10/11 x64 package from your store or official release. Keep your receipt. Redeem your AppSumo code or Gumroad key on the activation page, download .rcslicense and import it when opening the app. The same code and email recover the same license.

Executables are not advertised as Authenticode-signed. Verify the source and SHA-256 checksum; do not disable antivirus. Contact support if Windows or your organization blocks installation.

02 / Set up your business

The setup assistant configures language, currency and access. If you choose a password, create your account and save the recovery key outside the computer. Set your restaurant name and target margin. Check the currency format before entering prices.

03 / Add ingredients and recipes

Record purchase cost and buying/usage units. Check the conversion factor, for example 1 kg = 1000 gr. Add ingredients and quantities to the recipe, check servings and confirm the selling price. Ingredient margin is not net profit: account for labor, overhead and taxes separately.

04 / Choose your work mode

In Settings → Work mode, choose Single PC for local work. To share, activate Server on the central PC. On the other PCs select Use another PC, enter IP and PIN, test and save. Restart when requested. Use a trusted local network; do not expose the port to the internet. Keep the server awake with the app open.

Connectivity depends on firewall, router and Windows settings. It is not certified for every network or multiple physical computers. Local records are not automatically merged into server records.

05 / Back up before you need it

Create backups from Settings → Backup and keep copies outside that PC. Test restoration in a separate environment. Also save your license and recovery key. Restoring a backup replaces records: check the file before confirming.
